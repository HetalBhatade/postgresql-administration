# PostgreSQL Physical Backup

## Objective

This module demonstrates different physical backup techniques available in PostgreSQL.

It covers offline (cold) backup, WAL archiving configuration, low-level backup API, and pg_basebackup through hands-on practice.

The content is based on practical lab exercises together with the PostgreSQL official documentation.

---

## Topics Covered

- Introduction to Physical Backup
- Offline (Cold) Backup
- WAL Archiving
- Archive Configuration
- Low-Level Backup API
- pg_backup_start()
- pg_backup_stop()
- pg_basebackup
- Backup Verification
- Physical Backup Best Practices
