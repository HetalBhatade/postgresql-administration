
# PostgreSQL Logical Backup and Restore

## Objective

This section demonstrates how to perform logical backup and restore operations in PostgreSQL using the built-in backup utilities.

It covers database-level backups, table-level backups, global object backups, compressed backups, and restoration techniques through hands-on practice.

The content is based on practical lab exercises together with the PostgreSQL official documentation.

---

## Topics Covered

- Introduction to Logical Backup
- pg_dump
- pg_restore
- psql Restore
- pg_dumpall
- Database Backup
- Table Backup
- Global Object Backup
- Backup Compression
- Backup Verification
- Restore Verification
- Production Backup Best Practices
